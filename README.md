## ✨ Features

- 🎀 **Grand Curtain Reveal** — velvet curtains part with one big tap
- 🎁 **Gift Box** — tap it, watch it shake, then... confetti EVERYWHERE
- 🎂 **Bouncy Birthday Banner** — "HAPPY BIRTHDAY VIROCHI!" in giant, glowing letters
- 🎉 **Pop Confetti!** button for on-demand celebration bursts
- ⭐ **More Sparkles!** button for a screen full of glitter and stars
- 🎵 **Play Music** button to replay the birthday tune
- 🎈 **Floating Balloons** — tap any balloon to pop it into a burst of ⭐✨💖🌸
- 👆 **Tap Sparkles** — every tap or click anywhere leaves a little magic trail
- 👑 A page made entirely for one very special princess

## 🚀 How to Run

Visit https://arnavpathi1472013-tech.github.io/Happy-Birthday-Virochi

# or

1. Download or clone this folder: `my-birthday-gift/`
2. Make sure these files exist:
   - `images/hero.jpg`
   - `images/illustration.jpg`
   - `audio/birthday.mp3`
3. Open `index.html` in any modern browser.
4. Tap the gift, pop the confetti, and enjoy! 🎀
